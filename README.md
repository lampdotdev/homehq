# Home HQ

Wes Bos's family dashboard: the day, calendar, chores, shopping and photos at a glance.

Made with [Lamp](https://lamp.dev), a Mac app that builds apps from a description and changes them as you ask.

## Remix it with Lamp

With Lamp, choose File → Open from GitHub… and paste this repository's address (`https://github.com/lampdotdev/homehq`): you get this exact wish, yours to change by asking, with the credits below kept. Don't have Lamp? [Get it](https://lamp.dev).

## Building it

Lamp builds this kind of app: it needs Xcode and signing on your Mac, which Lamp sets up. Open it in Lamp, above.
